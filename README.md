# Word Review（単語復習）

ブラウザで動く英単語の復習アプリです。

- 単語は Google スプレッドシートから読み込みます（`app.js` の `DEFAULT_SHEET_URL`、または「単語リスト」画面の「スプレッドシート連携」で変更）。
- 学習の記録・背景の設定は、使っているブラウザに保存されます。「記録」画面からバックアップを書き出し／読み込みできます。

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | 見た目・背景 |
| `app.js` | 動き（カード、記録、シートの読み込み、背景切り替え） |
| `words.js` | シートに接続できないときの予備の単語リスト |
| `bg.svg`, `bg-watercolor.jpg` | 背景画像 |
| `bgm.js` | BGM（コードで演奏する曲と、フリー音源の再生） |
| `music/` | フリー音源の置き場所（追加方法は `music/README.md`） |
